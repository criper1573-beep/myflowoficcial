# Script Board — доска скриптов диалогов

Простое веб-приложение (аналог Miro) для работы над скриптами диалогов с клиентами: карточки двух типов (сообщение клиента / наш ответ), связи между ними, генерация ответа по GRS AI и экспорт в PDF.

## Возможности

- **Карточки двух типов**: «Сообщение клиента» и «Наш ответ» (разная форма и цвет).
- **У каждой карточки**: название, текст (в карточке — первая строка; иконка открывает редактор текста в модальном окне), кнопка «Копировать», у карточек «Наш ответ» — кнопка «Сгенерировать ответ» (по контексту ветки через GRS AI).
- **Связи**: карточки можно соединять друг с другом (перетаскивание от точки соединения).
- **Настройки скрипта**: описание проекта/скрипта используется как контекст при генерации.
- **Скачать в PDF**: выгрузка всего скрипта в один PDF-файл.

## Запуск

1. В корне проекта должен быть настроен `.env` с ключами GRS AI:
   - `GRS_AI_API_KEY`
   - `GRS_AI_API_URL` (по умолчанию `https://grsaiapi.com`)

2. Собрать фронт (один раз или после изменений):
   ```bash
   cd blocks/script_board/frontend
   npm install
   npm run build
   ```

3. Запустить сервер:
   ```bash
   python -m blocks.script_board
   ```
   Либо из папки блока: `start.bat` (проверит наличие `dist`, при необходимости соберёт фронт).

4. Открыть в браузере: http://127.0.0.1:8780

**Если «Улучшить текст» или «Сгенерировать ответ» выдают ошибку** — проверьте, что в корне проекта есть файл `.env` и в нём задан `GRS_AI_API_KEY=ваш_ключ`. Проверка: откройте http://127.0.0.1:8780/api/check-grs — в ответе должно быть `"configured": true`.

## Переменные окружения

- `SCRIPT_BOARD_HOST` — хост (по умолчанию `127.0.0.1`).
- `SCRIPT_BOARD_PORT` — порт (по умолчанию `8780`).
- Генерация ответов использует общие настройки GRS AI из корня проекта: `GRS_AI_API_KEY`, `GRS_AI_API_URL`.

## Хранение проектов

Проекты сохраняются **на сервере** в `blocks/script_board/storage/projects.json`. С любого устройства (компьютер, телефон) при открытии одного и того же адреса (например https://script.flowcabinet.ru) отображается один и тот же список проектов и их содержимое. В браузере в localStorage хранится только id текущего выбранного проекта (какой проект открыт на этом устройстве).

## Разработка фронта

- Режим разработки с прокси на бэкенд:
  ```bash
  cd blocks/script_board/frontend
  npm run dev
  ```
  Фронт: http://localhost:5175. API-запросы проксируются на порт 8780 — бэкенд должен быть запущен отдельно (`python -m blocks.script_board`).
