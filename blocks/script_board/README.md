# Script Board — доска скриптов диалогов

Веб-доска скриптов диалогов с клиентами: карточки «сообщение клиента» и «наш ответ», связи, комментарии, автоукладка и экспорт в PDF. Скрипт пишет бот Соня через HTTP API. Встроенной генерации в доске нет.

## Возможности

- Карточки двух типов, связи между ними, дублирование, копирование и удаление.
- Комментарии и режим комментирования.
- Выбор и создание проекта. `scriptDescription` — контекст проекта для Сони.
- Автосохранение полной записи с ревизией. Если сервер ответил 409, доска перечитывает проект. Если сервер недоступен, правка остаётся в памяти и повторяется с той же ревизией, а не пишется в localStorage.
- Опрос актуальной ревизии раз в 12 секунд и при возврате на вкладку, пока локальных правок нет.
- Скачать в PDF: html2canvas и jsPDF.
- История правок: `GET /api/projects/{id}/history`. Клиент для будущей панели: `useHistory` и `api` во фронте.

Контракт для бота: [API.md](API.md). Выкладка: [docs/guides/DEPLOY_SCRIPT_BOARD.md](../../docs/guides/DEPLOY_SCRIPT_BOARD.md).

## Запуск

1. Собрать фронт:

   ```bash
   cd blocks/script_board/frontend
   npm ci
   npm run build
   ```

2. Запустить сервер из корня репозитория:

   ```bash
   python -m blocks.script_board
   ```

   Либо `start.bat` в папке блока: при отсутствии `dist` он собирает фронт.

3. Открыть http://127.0.0.1:8780

## Переменные окружения

- `SCRIPT_BOARD_HOST` — хост, по умолчанию `127.0.0.1`.
- `SCRIPT_BOARD_PORT` — порт, по умолчанию `8780`.
- `SCRIPT_BOARD_STORAGE` — каталог хранилища, если он не `blocks/script_board/storage`.

## Хранение

Проекты лежат в `blocks/script_board/storage/projects.json`. История — в `storage/history/<projectId>.jsonl`. В localStorage браузера остаётся только id открытого проекта (`script_board_current`). Содержимое проектов туда не пишется.

## Разработка фронта

```bash
cd blocks/script_board/frontend
npm run dev
```

Фронт: http://localhost:5175. Запросы `/api` проксируются на порт из `vite.config.ts`. Бэкенд запускается отдельно.
